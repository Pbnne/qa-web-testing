# qa-web-testing
Описание сайта визитки

Сайт визитка создан для представления Овчаренко Павла Дмитриевича, специалиста в тестировании веб-приложений. Визитка включает информацию о его опыте, навыках и проектах.
Структура сайта:

1. Заголовок: Заголовок сайта "Визитка-портфолио", который привлекает внимание и отражает цель страницы.
   
2. Навигация: Удобное меню позволяет посетителям легко перемещаться по разделам сайта:
   • Обо мне: Краткая информация о Павле, его опыте и стремлении стать экспертом в сфере тестирования.
   • Проекты и учебные достижения: Ссылки на его проекты, расположенные на GitHub и других платформах, с кратким описанием.
   • Навыки: Перечень знаний и умений в области тестирования и программирования.
   • Контакты: Информация для связи.

3. Изображение: Личное фото для создания более дружелюбного представления о владельце визитки.
Цели сайта:
• Презентация профессиональных навыков и достижений.
• Упрощение общения с потенциальными работодателями или клиентами.
• Обеспечение доступности информации о проектах, над которыми работал Павел.
Дизайн:
Сайт использует современный и минималистичный дизайн, что обеспечивает легкость восприятия информации. Шрифты и цветовая схема выбраны так, чтобы гармонично сочетаться и способствовать удобству чтения.
